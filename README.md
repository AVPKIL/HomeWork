# Обработка банковских операций

Проект предоставляет функции для обработки списка банковских операций:

* **Маскировка номера карты** (get_mask_card_number).
* **Маскировка номера счёта** (get_mask_account)
* **Фильтрация операций** по статусу (filter_by_state).
* **Сортировка операций** по дате (sort_by_date).

## Цель проекта
Упростить обработку списка транзакций, полученных из базы данных, с возможностью:
- Маскировки номера карты или номера счёта
- Фильтрации по статусу (например, EXECUTED, CANCELED).
- Сортировки по дате 

## Установка
1. Скопируйте код функций в ваш проект файлы: masks.py, widget.py, processing.py

## Использование
### 1. Функция `get_mask_card_number`

Функция принимает на вход номер карты и возвращает ее маску.

**Параметры:**
* `card_number` - номер карты

**Пример:**
```
7000792289606361     # входной аргумент
7000 79** **** 6361  # выход функции
```

### 2. Функция `get_mask_account`

Функция принимает на вход номер счета и возвращает его маску.

**Параметры:**
* `account_number` - номер счёта

**Пример:**
```
73654108430135874305  # входной аргумент
**4305  # выход функции
```

### 3. Функция `filter_by_state`
Функция фильтрует список операций по статусу.

**Параметры:**
* `list_dict` — список словарей с операциями.
* `state` — статус для фильтрации (`EXECUTED` по умолчанию).

**Пример:**
```
Входные данные:
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
```
Выходные данные:
# Выход функции со статусом по умолчанию 'EXECUTED'
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

# Выход функции, если вторым аргументов передано 'CANCELED'
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```

### 4. Функция `sort_by_date`
Функция возвращает список отсортированный по дате

**Параметры:**
* `list_dict` — список словарей.
* `reverse` — порядок сортировки (True — новые сначала, False — старые сначала).

**Пример:**
```
Входные данные:
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
```
Выходные данные:
# Выход функции (сортировка по убыванию, т. е. сначала самые последние операции)
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
```

#### Функция `filter_by_state`
* Тестирование фильтрации списка словарей по заданному статусу `state`.
* Проверка работы функции при отсутствии словарей с указанным статусом `state` в списке.

* Тестирование сортировки списка словарей по датам в порядке убывания и возрастания.

* Тесты на работу функции с некорректными или нестандартными форматами дат.
