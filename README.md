# Обработка банковских операций

Проект предоставляет функции для обработки списка банковских операций:

* **Маскировка номера карты** (get_mask_card_number).
* **Маскировка номера счёта** (get_mask_account)
* **Фильтрация операций** по статусу (filter_by_state).
* **Сортировка операций** по дате (sort_by_date).
* **Фильтрация по валюте** (`filter_by_currency`)
* **Генератор описаний транзакций** (`transaction_descriptions`)
* **Генератор номеров карт** (`card_number_generator`)

## Цель проекта
Упростить обработку списка транзакций, полученных из базы данных, с возможностью:
- Маскировки номера карты или номера счёта
- Фильтрации по статусу (например, EXECUTED, CANCELED).
- Сортировки по дате 
- Генерации номеров карт и извлечения описаний операций

## Установка

## Использование
### 1. Функция `get_mask_card_number`

Функция принимает на вход номер карты и возвращает ее маску в формате `XXXX XX** **** XXXX`

**Параметры:**
* `card_number` - номер карты

**Пример:**
```
7000792289606361     # входной аргумент
7000 79** **** 6361  # выход функции
```

### 2. Функция `get_mask_account`

Функция принимает на вход номер счета и возвращает его маску, оставляя только последние 4 цифры

**Параметры:**
* `account_number` - номер счёта

**Пример:**
```
73654108430135874305  # входной аргумент
**4305  # выход функции
```

### 3. Функция `filter_by_state`
Функция фильтрует список операций по статусу.

**Параметры:**
* `list_dict` — список словарей с операциями.
* `state` — статус для фильтрации (`EXECUTED` по умолчанию).

**Пример:**
```
Входные данные:
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
```
Выходные данные:
# Выход функции со статусом по умолчанию 'EXECUTED'
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

# Выход функции, если вторым аргументов передано 'CANCELED'
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```

### 4. Функция `sort_by_date`
Функция возвращает список отсортированный по дате

**Параметры:**
* `list_dict` — список словарей.
* `reverse` — порядок сортировки (True — новые сначала, False — старые сначала).

**Пример:**
```
Входные данные:
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
```
Выходные данные:
# Выход функции (сортировка по убыванию, т. е. сначала самые последние операции)
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
```

### 6. Функция `transaction_descriptions`
Генератор описаний транзакций

**Параметры:**
* `transactions` — список транзакций.

**Пример использования функции:**

    print(next(descriptions))

### 7. Функция `card_number_generator`
Генератор номеров карт в заданном диапазоне

**Параметры:**
* `start` — начальный номер (от 1)
* `stop` — конечный номер (до 9999999999999999)

**Пример использования функции:**
```
for card_number in card_number_generator(1, 5):
    print(card_number)

>>> 0000 0000 0000 0001
    0000 0000 0000 0002
    0000 0000 0000 0003
    0000 0000 0000 0004
    0000 0000 0000 0005
```

### 8. Декоратор `log`
Автоматически регистрирует детали выполнения функций: название, время вызова, передаваемые аргументы, результат выполения и информация об ошибках.

**Пример использования декоратора:**
```
@log(filename="mylog.txt")
def my_function(x, y):
    return x + y

my_function(1, 2)

Ожидаемый вывод в лог-файл `mylog.txt` при успешном выполнении:

my_function ok

Ожидаемый вывод при ошибке:

my_function error: `тип ошибки`. Inputs: (1, 2), {}

Где `тип ошибки` заменяется на текст ошибки.
```
